# 直接接到现有串口画面

你的板子已经返回船的位置。这部分只增加“按这个位置找配套激光点、算距离”，不重新检测，不接管串口，也不加载 BP-Net。

1. 将本文件夹整体放进你的上位机工程，保留 `ship_range.py` 和 `data/` 的相对位置。
2. 在你的现有 Python 环境确认可以 `import numpy`。本次验证版本是 NumPy 1.24.4。
3. 程序启动时创建一次 `ShipRange()`。
4. 完整收到一帧、已经知道对应图片、准备画船框时，调用 `measure()`。
5. 返回 `valid=true` 时显示距离；否则显示“距离不可用”。不沿用旧距离，不让一个目标的距离覆盖另一个目标。

最小调用：

```python
from ship_range import ShipRange

ranger = ShipRange()

# 这里用你刚收到的真实板卡结果，不使用参考文件里的固定框。
boxes = [{"xyxy": [x1, y1, x2, y2], "track_id": ship_id}]
answers = ranger.measure(
    current_image_path,
    boxes,
    box_source="board_serial",
    sequence_id="POHANG00_RANGE",
    frame_id=current_frame_id,  # 本包板端编号为 0、1、2
)

for answer in answers:
    label = f"距离 {answer['distance_m']:.1f} 米" if answer["valid"] else "距离不可用"
    # 用你原来的画文字函数，把 label 写在对应船框旁。
```

`接入示例.py` 演示如何把常见的 x1、y1、x2、y2 字段接入；字段名不同只改这一处。

## 图片和位置要对应

- 必须使用 data/images 中提供的同一张去畸变 PNG，或内容字节完全相同的副本；不能换成原来的 SeaShips 图，也不能把另一张照片重命名冒充同一帧。
- 01 里的 data/manifest.json 与 02 的 BOARD_BINDING.json 固定了板端 0/1/2 与原始 012000/012010/012020 的映射。
- 当前图片按 SHA256 匹配；未知图片、错误组号、错误帧号会返回不可用。
- 默认传原图上的框：本包原图为 2048×1080。
- 如果板子返回的是直接拉伸到 416×416 输入上的框，显式传 `box_size=(416,416)`。
- 如果界面有留黑边、裁剪、等比例缩放，先用你现有的坐标转换还原到原图，不要直接传窗口上的位置。
- 若是跟踪结果，优先传用于画框的 `display_x1` 等字段，不传内部预测框。
- 收到一个完整帧后，把这个帧的所有框一次交给本模块。它不更新跟踪器，重复测距不会生成新 ID。

如果你已有别的组号，可以按你现有程序建立映射，再传入此包约定的照片组；不要仅凭帧号 0 就把另一组的第一张图配到这里。

## 先做接口试运行

在本文件夹运行：

```powershell
python test_integration.py
```

正常会输出 3 次 PASS 和一次总 PASS，参考框下距离约为 48.772、48.677、48.866 米。这个测试使用冻结的电脑参考框，**不是串口、板卡或你的 GUI 已联调成功的证明**。

实际板卡框回来后，会按实际框重新选点算距离；因此点数或数值可能与参考值不同，不要求把输出调成同样的数字。

## 这个版本的范围

只计算配套真实激光测点的船体可见表面代表距离，完全不依赖 BP-Net 推理。点云文件很小，按帧首次读取后缓存；不对每帧再跑大网络。

`valid` 只代表当前框内存在满足规则的深度支持，不代表检测一定是船，也不代表经过独立精度验证。沿用你们已有的检测/跟踪筛选，保留失败样例。当前没有接真实摄像头或实时激光雷达。

如果把代码放进 GUI，建议在已有的数据处理线程里调用，拿到结果后由原来的界面更新流程显示。
