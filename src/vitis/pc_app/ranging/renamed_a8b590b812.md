# 检测＋跟踪＋单目测距

上位机运行模式包含：

- **仅检测**：保持原有行为，不运行深度模型。
- **检测＋跟踪**：保持原有行为，不运行深度模型。
- **检测＋跟踪＋测距**：板端执行检测与跟踪，电脑端使用当前单目深度模型估计每个船框的距离。

界面不再提供独立的测距模式或点云/单目/融合选择。测距只作为“检测＋跟踪＋测距”完整流程的一部分运行。

单目结果显示为“单目估距 ~xx.x m”。`~` 表示该数值来自模型估计，并非激光实测距离。

## 数据语义

- 输出是船框内部区域的相机前向 Z 深度中位数。
- 结果 JSON 包含 `range_backend=monocular`、`estimated_not_observed=true`、深度分位数和内部一致性信息。
- 当前单目模型在 SeePerSea 测试集上的 MAE 为 6.52 m，但在三帧 Pohang 样例上存在明显跨域尺度误差，不能把该数值当作经过本地场景验证的精度。
- 当前测距可用于功能展示和后续算法研究，不应直接作为安全关键碰撞决策的唯一依据。
