# FPGA 工程复现与验证

适用于 HLS 算子、图像处理、矩阵计算和软硬件集成，不依赖特定检测网络。先确认修改范围与既有基线，在副本中验证。

1. 记录工具版本、器件、时钟约束、源码与测试输入 SHA256；区分继承产物和本次重建。
2. 按工具启动、依赖配置、编译链接、数值、接口、整机运行分层定位。BSP include/lib 应来自同一配置；从实际 cwd 解析相对路径。
3. 将 dtype、layout、shape、字节数、量化缩放与舍入饱和规则写为接口契约。整数 DUT 使用独立整数参考；浮点参考按明确容差比较。
4. 覆盖单块、多块、尾通道、边界、负数与饱和。输出增加保护区；输入用精确容量和地址检查。输出保护区通过不能证明输入读取合法。
5. DUT、参考模型、仿真元数据的修改分别留 diff；不得扩大映射范围掩盖非法访问。
6. C 仿真、HLS、RTL 协同仿真、整机实现、软件链接、启动打包与实板运行分别列状态。外层退出码、内部错误计数、预期报告共同判定。
7. 同器件同约束比较资源与时序，区分 HLS 估算和布线结果；检查 setup/hold、未约束路径与 DRC。

每个问题输出：触发条件、命令/cwd、失败日志、假设与证据、修改、复测、影响范围、遗留项。无实板不标记板端通过。

来源与效果：原 ship-fpga-reproduction 材料记录了单 tile 后缀 5408 元素覆盖、BSP 相对路径错误、旧 bit 混入候选 BOOT、仿真映射掩盖非法读取等观察。这些历史结果本次未重新执行。原跟踪缓存不随本技能分发。

失效条件：缺少原始源码/工具许可/目标硬件时只能完成相应阶段；无法由链接或打包成功推断板端功能。非 HLS 或特殊缓存架构需调整验证方法。
